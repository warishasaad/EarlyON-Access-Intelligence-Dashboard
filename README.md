This project presents a comprehensive geospatial and operational analysis of EarlyON Child and Family Centre programs across Toronto and the Peel Region. Built using Tableau, the dashboard enables users to explore program availability (Available, Limited, Unverified), identify the closest and farthest service centres relative to community locations, and understand program distribution by day, time slot, language, and ward.
Key features include an interactive map with color-coded proximity logic, program availability breakdowns by morning/afternoon/evening slots, school vs. community-based program comparisons, and language availability filtering across 25+ Toronto wards. The dashboard is designed to help policymakers, community planners, and families make informed decisions about early childhood service access.
